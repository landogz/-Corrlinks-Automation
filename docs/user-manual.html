1. What this app does

Inside Scores is a desktop app that:

  1. Signs you into SportsData
  2. Loads inmate CorrLinks accounts and exchange files
  3. Validates CorrLinks logins (Preparing your workspace)
  4. Opens CorrLinks, composes messages, and sends selected exchange file parts
  5. Supports a Start loop mode to send to many recipients across CorrLinks accounts
Clock, log stamps, history date, and daily subject always use America/New_York — your Mac or Windows display timezone does not matter.

3.2 macOS

  1. Open the matching .dmg and drag Inside Scores into Applications.
  2. First open (unsigned): right-click → Open → confirm, or run: 
    xattr -dr com.apple.quarantine "/Applications/Inside Scores.app"
  3. Launch from Applications / Launchpad.

3.3 Windows

  1. Run Inside-Scores-Setup-x.y.z.exe (recommended).
  2. If SmartScreen appears: More info → Run anyway.
  3. Open Inside Scores from the Start menu.

Portable .exe works without install but does not auto-update — prefer the Setup installer.

4. Sign in (SportsData)

  1. Enter SportsData email and password.
  2. Leave Remember me checked to save login on this computer.
  3. Click Sign in.

Theme (Auto / Light / Dark) can be set on the login screen or from the account menu. Sign out from the account avatar → Sign out.

6. Preparing your workspace

First validation probes each unique CorrLinks account. When a new login is added (or a password changes), the overlay probes only those new/changed logins — not every account again.

  • Overlay shows status, percent, and failed accounts.
  • Tags may include Locked, Timeout, or Error.
  • Use per-account Retry, or Continue without retries.
  • Cancel aborts the prep run.

Use the Accounts tab for Validate new, Refresh all, or per-row Retry. Top-bar Refresh forces a full re-probe.

7. Daily work — single inmate

  1. Open Automate.
  2. Search and select an inmate (name, ID, or email).
  3. Choose Daily or Weekly update (NFL / CFB).
  4. Check the exchange file parts to send. Each row has Copy and Download.
  5. Click Send all files.

The app logs into CorrLinks, opens compose, sets To and subject, pastes each checked part, and sends. Use Force stop / Stop loop to halt a running job.

8. Start loop (many recipients)

  1. Complete workspace validation at least once.
  2. Choose template and checked file parts.
  3. Click Start loop.
  4. Watch progress, countdown between accounts, and failed recipients.
  5. Use Retry failed from the panel or completion dialog if needed.

Only checked files are sent. The To field is cleared between recipients.

11. History tab

  1. Open History.
  2. Pick a date (New York calendar) → Export for date.
  3. Select a row to preview; use Copy, Download, or Export CSV.
  4. Refresh reloads the list; filter by date in the search box.

12. Status log

Open with the log button or ⌘/Ctrl + J.

  • Filter by level; search text
  • Auto-scroll; Mask emails
  • Copy or Clear (⌘/Ctrl + K)

Toasts show success and error feedback during sends and validation.

15. Optional .env

Usually not required after in-app sign-in.

SPORTSDATA_BASE_URL=https://sportsdata.com
SPORTSDATA_EMAIL=your-email@example.com
SPORTSDATA_PASSWORD=your-password
# Documentation only — app is hard-locked to America/New_York
APP_TIMEZONE=America/New_York
CORRLINKS_SIGNIN_DELAY_MS=5000

Do not share a filled .env or credentials file.

17. Privacy & safety

  • Password is stored only when Remember me is checked.
  • Enable Mask emails before sharing logs.
  • Never commit credentials or paste them into public tickets.
